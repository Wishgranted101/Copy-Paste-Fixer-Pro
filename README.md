# Copy-Paste Fixer Pro

![Chrome Web Store](https://img.shields.io/chrome-web-store/v/fpjppnhnpnknbenelmbnidjbolhandnf?label=Chrome%20Web%20Store&style=for-the-badge ) ![Users](https://imgshields.io/chrome-web-store/users/fpjppnhnpnknbenelmbnidjbolhandnf?style=for-the-badge )

## 🚀 Unlock Your Web: Copy, Paste, and Right-Click Without Breaking Your Browser!

**Copy-Paste Fixer Pro** is a lightweight, intelligent Chrome Extension designed to restore your fundamental browser functionalities on websites that restrict them. Tired of extensions that enable copy-paste but disable your keyboard shortcuts, break video players, or interfere with critical web applications like Google Docs or Discord? We were too.

This extension provides a surgical solution, activating only when you need it, ensuring your browsing experience remains seamless and uninterrupted.

## 💡 The Problem with Existing Solutions
Many existing "enable copy-paste" extensions take an overly aggressive approach, often breaking essential website functionalities. Users frequently report issues such as:

*   ❌ **Broken Keyboard Shortcuts:** Spacebar not pausing YouTube videos, Enter key creating new lines instead of submitting messages in chat apps (Discord, Google Chat).
*   ❌ **Interference with Web Apps:** Google Docs, Spotify, and Gmail often become partially unusable.
*   ❌ **Global Activation:** Extensions are always-on, causing unexpected behavior even on sites where copy-paste isn't blocked.

## ✨ How Copy-Paste Fixer Pro Solves It

We don't believe in brute force. **Copy-Paste Fixer Pro** employs a smart, selective approach:

*   **Surgical Activation:** The extension only injects its fix when you explicitly activate it for the current tab, preventing global interference.
*   **Non-Intrusive Logic:** Our core script targets only the specific JavaScript events that block copy, paste, and right-click, leaving your keyboard shortcuts and other site functionalities completely untouched.
*   **Manifest V3 Native:** Built from the ground up for the latest Chrome Extension standards, ensuring stability and future compatibility.

## 🚀 Features

*   **One-Click Activation:** Easily enable copy, paste, and right-click for the current tab with a single click on the extension icon.
*   **Preserves Keyboard Shortcuts:** Enjoy uninterrupted use of your favorite websites without fear of breaking essential keyboard commands.
*   **Restores Context Menus:** Regain full control over right-click menus on restricted pages.
*   **Visual Feedback:** A clear indicator (e.g., an "ON" badge) shows when the extension is active on a tab.
*   **Lightweight & Fast:** Designed for minimal resource usage, ensuring a smooth browsing experience.

## 🛠️ Installation

### From the Chrome Web Store (Recommended)

1.  Visit the [Copy-Paste Fixer Pro page on the Chrome Web Store](LINK_TO_CHROME_WEB_STORE_PAGE_HERE).
2.  Click "Add to Chrome."
3.  Confirm the installation.

### From Source (For Developers)

1.  Clone this repository:
    ```bash
    git clone https://github.com/Wishgranted101/copy-paste-fixer-pro.git
    ```
2.  Open Chrome and navigate to `chrome://extensions/`.
3.  Enable "Developer mode" using the toggle in the top right corner.
4.  Click "Load unpacked" and select the cloned `copy-paste-fixer-pro` directory.

## 💡 Usage

1.  Navigate to a website where copy, paste, or right-click is blocked.
2.  Click the **Copy-Paste Fixer Pro** icon in your Chrome toolbar.
3.  Click the "Enable on this site" button in the pop-up.
4.  The extension will activate, and you should now be able to copy, paste, and right-click freely on that page.
5.  The extension will remain active for that tab until you close it or explicitly disable it.
